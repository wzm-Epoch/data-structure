# 链表章节设计与实施

用户要求继续链表章节，并让功能丰富全面。沿用现有本地静态项目和学习风格，扩展独立链表页面，共用原有输入解析和基础样式，顺序表页面保留。

## 本次范围

- 带头节点的单链表：按位查找、按值查找、插入、删除、遍历、迭代逆置、头插建表、尾插建表。
- 非循环双链表：按位插入、按位删除，展示 next 与 prior 的逐句更新。
- 带头节点循环单链表：插入、删除、遍历，以回到头节点为终止条件。
- 插入错序实验：正确顺序与错误顺序对照，检测自环和失去头节点可达性的节点。错误示例停止在已知结构异常处，不执行任何无效解引用。
- 概念导读、结构对比、复杂度说明、13 道原创自测、常见错误解释。
- 播放、单步、回退、时间线、预测、在链接改写/内存释放前暂停、执行记录跳转、节点观察、预置边界输入、复制最终值继续操作、下载 C 代码。
- 独立保存链表学习记录，不覆盖顺序表的记录。

## 模型与约定

逻辑位置从 1 开始，头节点位置为 0，头节点不存储有效元素。节点身份使用 H、N1…和 S 等符号，不是实际内存地址。渲染布局保持节点身份稳定，箭头完全取自每步的 next/prior 字段；布局相邻不表示物理内存连续。

快照包含节点图、活动指针、标量、行号、解释、条件结果、写入字段、访问节点、输出和返回结果。初始状态未执行，之后均显示执行后状态。free 后节点以墓碑形式保留用于观察，但字段不再显示可读取值；局部指针保留符号身份并提示已释放，结束后作为退出前观察记录。

建表算法以已有空头节点开始；输入列表是待插入数据流。malloc 可在第 k 次申请失败，用于覆盖失败分支；失败的构建返回 false，但已建部分保留在 L 中并由调用方管理。页面明确区别于插入失败时链表保持不变。

最初输入最多 8 个数据节点，仅限制可视化规模，不代表链表有固定容量。允许插入得到第 9 个数据节点。位置、元素为 32 位整数。双链表终点为 NULL，循环链表终点为 H。reverse 只修改 next，不交换节点数据。

## 验证计划

检查所有算法的空表、单节点、普通情况、重复值、负值、首尾位置、非法位置、查找失败与内存分配失败。验证每个读写访问合法，快照独立，结束结构无意外环/悬空链接；双链表双向一致，循环表回到头节点。通过实际 C 编译运行对照最终值、输出、返回结果和分配失败场景。浏览器检查各类型切换、代码/图同步、回退、预测、断点暂停、边界示例、练习、下载和原顺序表回归。
