# 串章节设计（2026-11-05）

采用独立 string.html、string.css、js/string-engine.js、string-content.js、string-app.js，复用现有视觉规范；不改造旧章节引擎。另一方案是合并现有播放器，但会扩大旧章回归范围，本次不采用。用户已授权常规实现细节自行安排。

按基本操作 → BF → KMP 构表与匹配 → nextval 与对比推进。每阶段运行引擎检查。课程、自测与独立进度键 zhixu-string-v1 配套交付。

显式 length 的定长串，网页容量 M 可设 1–32，支持可打印 ASCII 32–126，保留空格；拒绝控制字符及其他字符。位置 p 从 1 开始，允许零长度子串/删除在 n+1 处操作。所有输入串长度不超过 M。操作失败保持 S 不变；替换使用临时串，左到右非重叠扫描原串，最后提交。

采用结构化语句描述同时生成页面 C 与语义轨迹，条件、赋值、循环均逐句保存；初始未执行。快照包含四个串、局部变量、表、访问项、比较、计数和结果。只解释预置语句，不能编辑或运行任意 C。

next/nextval 有效匹配表项 0..m-1，首项 -1。额外 terminal 项 index=m 保存完整模式的最长真边界长度，专供完整匹配后重叠继续；绝不读取 P[m]。空模式首次返回 1，全部匹配定义为所有 n+1 个字符边界，两种重叠策略相同。失败返回 0。BF、next、nextval 共用全部/首个与重叠开关；对比模式统一输入、分别统计构表与匹配字符比较，允许切换完整轨迹。

匹配使用计数辅助函数 Eq；循环条件不计字符比较。nextval 构造的额外字符判断也计入预处理。nextval 终端项保留普通边界值。播放支持关键事件前暂停及再次播放越过当前暂停点；预测错误可重选；时间线与日志直接恢复快照。构表显示候选前后缀与已知表值。

验证：独立参考穷举全部位置、边界操作、字符读写及快照独立性、页面同源 C 实际编译比较最终结果/两张表/比较数，浏览器新章交互与旧章回归。验证范围与限制如实记录，不声称教材或考纲完整覆盖。
