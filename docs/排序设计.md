# 排序章节设计

2026-11-05，0.8.0。依据用户完整需求增量建设，常规实现安排已获授权；使用原创C及讲解，无教材复刻或完整考纲覆盖承诺。

## 结构与取舍

独立sort.html/sort.css，复用styles.css配色、侧栏、课程页签和播放按钮风格；旧七章增导航，旧章引擎与进度键保持原样。排序进度键zhixu-sort-v1。原项目尚无可独立复用的通用播放器，本章不抽取旧章控制器，降低回归范围。

js/sort-runtime.js负责固定语句树编译与解释，sort-internal/external.js保存算法语句，sort-engine.js做解析、参数契约、终态验收和C生成，sort-content.js课程/练习，sort-render.js图示，sort-app.js播放及进度。无需构建、外部库、CDN、API或账号。可直接打开HTML；开发验收走本地HTTP。

与复制一份独立C再手写另一份动画相比，本章固定语句同时生成C及轨迹；与合并所有旧章执行器相比，新执行器隔离记录/桶/外存语义。表达式仅来自内置模型，用户整数和身份作为数据进入数组。网页不是任意C编译器。

## 执行与记录

记录含int32 key、字符串id、原输入order。C对照将id映射为独立整数，不作为关键字平局条件。数组下标0、逻辑位置1；比较用关系运算，不作key相减。文本解析重建身份，结果续接保留身份并以新实验输入重置order。外部段生成结果续接到二路归并，保留分段。

初态line=null且尚未执行；条件、赋值、调用、返回和返回接收独立快照。含A/B/R/S/H、计数桶、段长度/游标、比赛树、活动/冻结标志、完整记录、局部暂存、调用栈及返回行、判断、读写、阶段、比较及全部计数。局部尚未初始化用null观察，解释器拒绝读取。记录赋值深复制，快照互不共享。中间A可暂有重复，不能用终态排列约束伪造搬移过程。

PutA/B/R/S/H是一次完整记录写入的基础操作，C函数体明确显示。Swap保存t并执行两次PutA，跳过i==j；交换期间也逐步保存。辅助区采用固定有界教学存储，Alloc表示一次辅助区准备及可注入失败，失败在主数组写入之前返回；不是系统malloc实现。

## 内部算法

15入口：直接插入、上界式稳定折半插入、严格递减增量希尔、普通/提前结束冒泡、末元素Lomuto快速、首元素三路快速、交换式选择、交换式下沉堆、递归/迭代归并、双有序段归并、稳定计数、十进制LSD基数、桶内直接插入的桶排序。

快速闭区间，Lomuto左侧严格小于枢轴、右侧大于等于，返回枢轴最终下标；三路等值区排除递归，展示lt/i/gt。堆数组与树按槽位同步，升序大根、降序小根。归并相等取左，分别统计写B和回写A。希尔展示间隔子序列而非连续前缀。

计数R=max−min+1≤256，负值偏移；升序逆向稳定放置，降序正向n−C[k]放置。基数升序key−min、降序max−key，差值均由int64_t承接，最大4294967295；除数1..10^9，更新后最多10^10，安全终止，不对INT_MIN取负。桶号floor(mapped*k/R)，0..k−1；按输入顺序入桶，桶内稳定插入，桶号递增收集。方向改变不整体反转结果。

展示上限32条、桶数1..16、增量1..32且严格递减末项1；split只对双段实验校验，不让无关参数阻止空数组。小规模限制均明确为展示限制。

## 外部实验

5入口：按M容量直接插入生成初始段、二路归并、扫描候选多路归并、缓存胜者的败者树、置换—选择。R/S代表外存段存储角色，H保存输入缓冲头；缓冲块由当前Pos与B确定。输出满B或段末残块写出，输入每次首次进入块计一次读。FlipRuns只交换存储角色，不计额外磁盘I/O；最终汇总A是观察输出，不计磁盘读写。段生成只保证每段有序。

k路要求M≥(k+1)B。置换选择保留输入/输出各B，工作槽P=M−2B≥1；扫描活动槽选候选，按方向小于last的新记录冻结，活动耗尽解冻。空槽/耗尽用Flag、Pos、Lens和无效段编号−1表示，合法int32关键字不充哨兵。相等外部候选按原order稳定决胜。扫描候选版O(nP)，不宣称堆实现复杂度。

败者树Loser存内部败者，W缓存每个子树胜者；补齐至2的幂，无段叶−1。Match记录一场比赛，胜出叶到根逐级更新。页面同时显示树、败者数组、胜者缓存、当前帧p、实际读写和日志路径。额外缓存保持O(k)空间、更新O(log k)。可选最优归并树本次未实现。
