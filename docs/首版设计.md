# 408 数据结构学习工具 · 首版设计

## 已确认需求
用户希望从数据结构逐步扩展到算法，通过动态演示理解每行代码。目标为 408，意向参考王道 2027，但当前没有教材。用户已同意继续首版：中文本地网页、顺序表概念、访问、插入、删除；同步代码、结构、变量和解释，支持回退、播放、暂停、重置、修改输入和预测下一步。

## 方案选择
采用没有外部依赖的 HTML/CSS/JavaScript 本地项目。与单次独立演示相比，公共播放组件和课程注册表可以复用；与需要账号及服务器的平台相比，可离线运行，启动负担低。后续课程逐步接入同一轨迹结构。

## 首版行为
- 原创 C 示例。位置 i 从 1 开始，数组下标从 0 开始。
- 固定容量可选 6、8、12，页面代码 MAXSIZE 与选择同步。
- 预置三种算法，按语义生成完整执行轨迹；明确不是运行任意 C 代码。
- 每个快照包含物理数组、逻辑长度、局部变量、已执行代码行、说明、读写位置、移动箭头、返回结果和累计移动次数。
- 所有高亮对应刚执行完的语句；初始状态未执行。for 循环拆分为初始化、条件、循环体、自增/自减，各步映射原语句行。
- 非法位置、满表触发 C 示例中的 false 返回。输入格式错误在表单显示，不生成虚假的执行状态。
- 删除后数组尾部可能残留旧值，位于逻辑长度外的格子标记为非表元素；不能把长度减一解释为擦除内存。
- 学习进度只保存在当前浏览器，提供清除进度入口。存储不可用仍可学习。
- 概念导读、逐行演示、自测练习和学习路线共用页面。未来章节标记规划中，不伪装成已实现。

## 验收
算法测试覆盖所有合法位置、空表、满表、非法位置、重复值、负数，以及每步只改变相应状态、快照不共享可变引用；与独立参考结果比较。浏览器检查播放、回退、输入、自测和窄屏布局。界面不包含教材复刻或完整考纲覆盖承诺。
