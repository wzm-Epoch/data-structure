# 栈与队列章节验证记录

日期：2026-11-05。版本：0.3.0。

## 约定与支持范围

用户指定顺序栈空栈 top = 0。本章 top 等于元素个数与下次入栈位置，满栈 top == M，栈顶 data[top−1]。链栈带头节点 H，top 为指向 H 的指针，实际栈顶为 H.next；两者含义明确区分。

循环队列预留一格，front 指向队头，rear 指向下一空位；物理容量 M，有效容量 M−1。链式队列带头节点，空队列 front == rear == H。重复值按独立元素处理。全部材料为原创，教学模拟仅支持预置算法。

四类结构共 22 项基本操作；应用算法、共享栈、双端队列等仅作概念或规划。初始化以空输入和已有有效对象为前提，链式头节点由调用方提供，不模拟头节点创建分配失败，也不直接覆盖非空链。
