执行 `node tests/linked-c-parity.cjs "D:\Dev-Cpp\MinGW64\bin\gcc.exe"`，898 个场景全部通过，覆盖 13 个正常算法。

直接使用页面中同一份 C 算法源代码，C11 编译运行。初始节点使用真实内存，算法内 malloc 可在指定次数返回 NULL。逐组比较逻辑序列、返回结果、删除/查找输出、Visit 输出、分配尝试和释放次数；还检查双向一致性、循环终止和清理。

该对照验证 C 算法的实际最终行为；中间快照由状态测试与浏览器检查验证。错序实验不作为可用算法运行，由结构异常测试单独验证。

## 范围与限制

- 依然没有原书材料，不声称复刻王道 2027 或已完整核对当年考纲。
- 逐行演示支持带头节点单链表、非循环双链表、循环单链表；不带头节点、循环双链表与静态链表目前仅为概念对照。
- 初始最多 8 个数据节点；新插入可得到第 9 个。此限制只为可读性。
- 预览浏览器禁止 file 协议，因此浏览器检查通过本地 HTTP 完成。页面本身使用相对路径、普通脚本和本地资源，不依赖网络 API、CDN 或模块加载。
