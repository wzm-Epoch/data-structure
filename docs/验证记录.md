## 验证限制

浏览器工具只允许 http/https，拒绝 file 协议。因此没有通过该工具实际验证直接双击 HTML 的入口。项目使用普通相对路径 CSS、defer 脚本，没有 fetch、ES modules、CDN 或外部字体；本地 HTTP 访问已验证。README 同时提供可复现的本地预览方法。
