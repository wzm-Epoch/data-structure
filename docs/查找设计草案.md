## 1. 已检查的项目与方案

现有六章采用离线 HTML、共享 styles.css、独立章节引擎/课程/控制器和独立 localStorage 键。树、图章节采用固定语句模型同时生成 C 和轨迹。树图渲染函数位于 tree-app.js 闭包，尚无独立导出接口；不能直接将旧控制器作为新章组件加载。

方案选择：

1. 推荐独立 search.html，章内分模块，复用视觉和交互约定。旧章仅修改导航及课程开放状态，旧引擎与记录格式保持原样。实现和回归范围清楚。
2. 抽取全部章节的公共播放器和绘图组件，可以减少重复，但会扩大旧章回归范围，不适合与本次复杂算法扩展同时进行。
3. 每种查找结构独立页面，文件隔离直接，但课程切换、进度和对比实验会分散。

采用方案 1。以下各结构分阶段实施与验收，阶段划分不缩减用户要求。

## 3. 公共模型与执行契约

关键字为 int32，负数、零、正数和两端边界均合法。数组内部下标 0 起、返回逻辑位置 1 起，静态查找失败 0；指针型接口失败 NULL。树与散列表为唯一关键字集合，重复插入返回已存在，结构不变。

节点用单调分配的独立身份表示，关键字复制不改变身份，释放身份不复用。结果续接保存存活身份与分配器；文本重建明确说明重新分配身份。树高按节点数，空树 0、叶子 1；层次根 1、深度根 0。

每一步保存执行后完整状态：源代码行、函数及调用帧、数组、节点池、根、链接、桶、局部变量、返回值、判断结果、读写字段、输出、计数和解释。初态 line=null，标注尚未执行。调用、返回、接收返回、条件及每条赋值分别保存。短路条件只记录实际读取。

固定语句描述同时生成页面 C、下载 C 和语义轨迹；用户输入仅作为数据。不得用终态插值生成动画。旋转、分裂、合并和修复均为可进入的逐句函数，不是一个原子动画。中间状态可暂时出现链接未接回、占用不合规或性质未恢复，图示如实展示，稳定不变量仅在适当检查点判定。

释放后墓碑只显示身份和释放事件，不显示可读取字段。未初始化字段与 NULL 分开。链接由当前快照决定；临时断开的节点仍可从分配池观察，不用布局假装保持树形。

修改初始数据、查询、块大小、阶数、散列参数或算法约定后，暂停并标记待生成；成功校验后重新生成全部轨迹，非法输入保留旧轨迹且明确其所属输入。改变布局不改变算法状态。

## 4. 数组查找与分块

实现普通顺序、额外哨兵、闭区间迭代/递归折半，以及首个等于、最后等于、首个大于等于、首个大于八种入口。

哨兵方案：将 n 个输入复制到 n+1 格工作数组 T，在 T[n] 写入目标，由前向后搜索；原数组不变。展示复制、哨兵写入和结果转换。完整实现额外空间 O(n)，不宣称 O(1)；比较次数与预处理复制次数分别显示。空输入仍有一个哨兵格。

普通折半统一闭区间 [low,high]，使用有符号下标，high=n-1，mid=low+(high-low)/2；空数组 high=-1。递归显示每层区间、基例和返回传递。重复值可返回任意匹配位置，不能用它冒充边界结果。

四种边界入口统一半开区间 [low,high)，初始 [0,n)。lower_bound 使用 A[mid]<key；upper_bound 使用 A[mid]<=key。最终下标可以为 n，展示插入边界；转换为题定逻辑位置时，仅存在满足条件的元素才返回下标+1，否则返回 0。首个等于由 lower_bound 核验，最后等于由 upper_bound-1 核验，先检查边界再读数组。

折半输入必须非降序，拒绝无序输入。一键排序为显式操作，替换输入框及实际数组，说明返回位置属于新数组。

分块支持按块大小自动划分及显式块边界，块内可无序。验证每对相邻块 max(left)<=min(right)，允许数组重复值；不能只检查块最大值递增。索引存块首、块尾和最大关键字。顺序或折半索引都定位第一个 max>=key 的块，再块内顺序查找；该条件下如关键字存在，最早候选块包含它。分别显示索引比较、块内比较与总数。

不同块大小实验使用同一数组，逐个验证划分是否合法；不合法方案不生成虚假代价。需要生成示例时明确采用非降序输入再按块划分，块内可显式打乱。查询集合与概率一并显示。

## 5. BST 与 AVL

BST：查找、插入、删除、最小/最大、前驱/后继、中序及严格有序检查。前驱/后继基于选定存活节点，明确无结果为 NULL。两孩子删除复制中序后继关键字，再摘除并释放后继节点；原目标身份保留。代码、字段变化和最终释放事件分开。

预置覆盖叶子、单孩子、双孩子、根、不存在；有序、逆序及混合插入使用同一集合，对比树高与查询代价。

AVL：空高 0、叶高 1，BF=h(left)-h(right)。插入和删除返回子树根，接回父链接时单独记录；沿路径更新高度，显示 LL/RR/LR/RL。删除按孩子 BF 的含零情况选择旋转，并继续向上检查，不能使用插入时的关键字方向替代删除判型。

旋转拆出保存局部指针、每条孩子链接改写、接回、两个高度更新。比较旋转前后中序序列，终态验证严格有序、实际高度与缓存高度一致、所有 |BF|<=1。

## 6. 红黑树

采用一个共享黑色 NIL 哨兵，普通节点的空孩子指向 NIL，根父指针为 NIL；空树 root=NIL。NIL 无关键字、不属于集合、不参与释放；其左右及 parent 固定指向自身。修复所需父信息通过局部 xParent 显式传递，不能依赖共享 NIL 上一个含混的 parent 值。

页面约定黑高 BH(v)：从 v 到后代 NIL 的任一路径上黑节点数，包含 v（若黑）与终点 NIL，因此 BH(NIL)=1。说明这是本实现口径，路径黑数一致才显示单一黑高。

插入：新节点红、父/祖父/叔身份、叔红变色、叔黑的内外侧旋转、对称分支、根黑。删除采用后继节点移植的标准方案，与 BST/AVL 的关键字复制方案在课程中分别标明；保持被移植节点身份，记录实际从原位置摘出的节点 y 的原颜色与最终释放的目标 z。

修复显示 x、xParent、兄弟及侄节点，覆盖 x=NIL、红兄弟、黑兄弟双黑孩子、近红远黑、远红及镜像情况。“额外黑色”是局部修复解释状态，节点持久颜色仍仅红/黑。

终态检查根黑、NIL 黑、红节点孩子黑、父子链接一致、所有根到 NIL 路径黑数相同及 BST 顺序。每个修复条件和每条变色/链接赋值保留独立快照。

## 7. B 树

支持 m=3、4、5：每节点最多 m-1 键、m 孩子；非根至少 ceil(m/2)-1 键，内部非根至少 ceil(m/2) 孩子。非空叶根至少 1 键，内部根至少 2 孩子；空树单独表示。

偶数阶 m=2t 时容量与最小度数 t 的定义对应；奇数阶不能直接代入整数 t 而同时得到相同上下界。

插入先向叶加入，出现 m 个键才分裂；提升下标 floor(m/2) 的关键字并从孩子移除。删除内部键使用前驱替换，再从叶删除，沿路径自下向上修复下溢；优先左兄弟借，再右兄弟借，无法借才合并。借位经父键轮转，合并包含父分隔键。不要先合并两个尚未下溢的最小节点，以免奇数阶超过容量。

展示节点内比较、孩子范围、数组移动、临时溢出槽、孩子搬移、父插入、根分裂/收缩及释放。终态验证节点键序、分隔值域、占用、孩子数=键数+1及等叶深。

## 8. B+ 树

明确采用本实现约定：内节点最多 m 孩子、m-1 分隔键；非根内节点最少 ceil(m/2) 孩子；叶容量 L=m-1，非根叶最少 ceil(L/2) 个数据键。根叶可为空，内根至少 2 孩子。

separator[i]=第 i+1 个孩子子树的最小数据键，等于分隔键时进入右孩子。数据仅存叶；内键是导航副本。单键查找返回叶节点及槽位，失败 NULL；不把内节点命中当作数据命中。

溢出后分裂，叶分裂复制右叶最小键到父而不从叶移除，内节点分裂重新形成各自分隔信息。删除后借位或合并，沿路径逐条更新受影响分隔键；最小键变化即使没有下溢也要向上维护。叶 next 与 prev 逐条维护，释放前摘链。空根收缩与树高降低单独展示。

范围查询固定闭区间 [a,b]，a>b 拒绝；先定位 lower_bound(a)，再仅沿叶链前进，逐键判定直到 key>b 或链尾。扫描入口从最左叶沿 next，不通过全树遍历伪装叶链输出。终态同时校验叶链无环、顺序、双向一致及恰好覆盖全部叶。

## 9. 散列表

桶编号 h(k)=((int64_t)k % M + M) % M，C 提升后运算，确保 INT32_MIN 也合法。除留余数法以可观察的映射步骤呈现，并供四种冲突方案共同使用。

开放定址槽状态 EMPTY/OCCUPIED/DELETED。查找遇 DELETED 继续，遇 EMPTY 失败；插入记首个墓碑，继续检查重复，确认不存在后才复用。探测结束仍可使用已记墓碑。

表长选择 7、11、13、17 等适当素数。线性 (h+i)%M；二次 (h+i*i)%M；双重 (h+i*d)%M，d=1+normalizedMod(k,M-1)，确保与 M 互素。i=0..M-1 有限终止，展示重复访问也计为探测。二次法不保证覆盖全表，失败分别报告表满或序列未到达剩余可用槽，不宣称仍有墓碑可复用时无法插入。

链地址采用每桶头指针和普通数据节点，查找 NULL 失败；接入、摘链、释放分步记录。观察 alpha=n/M、每桶元素分布、墓碑数与实际冲突/探测序列。动态扩容列为进阶可选，不作为基础功能完成的替代。

## 10. 性能、ASL 与课程

统一使用 C 中可计数的 CompareKey/EqKey 辅助函数；一次实际调用计一次关键字比较，不用 a-b 比较 int32 以避免溢出。整数边界判断、链接检查、颜色判断不计关键字比较。若同一键对被代码重复比较，按实际调用重复计数。

分别统计关键字比较、节点进入次数（重复进入重复计）、散列槽探测、单旋次数（双旋计 2）、分裂与合并；另列不同节点数、索引/块内比较和初始化成本。访问节点数与比较次数不能相互代替。预建、查询、更新和验证开销分开；动画时长不参与性能结论。

六组实验覆盖用户指定配对，使用同一输入、查询集合及概率。跨数组与集合结构对比默认使用唯一值输入；如数组含重复值，明确展示集合去重后的输入，不暗称完全相同多重集。

默认有限查询列表，每个列表项等概率，允许重复查询表示权重；提供显式概率时验证非负且和为 1。按命中/失败分别条件化计算 ASL：sum(p_i*C_i)/sum(p_i)，分母是对应组概率质量。无成功或无失败样本显示“不适用”，不能显示 0。逐查询列成本、概率、贡献、结果并可打开轨迹。不把未查询的整数全集说成等概率。

课程采用概念导读、逐行演示、对比实验、易错专题、自测练习。提供每类修复与边界预置、预测下一步、关键改写/旋转/释放前暂停、播放调速、完整回退、日志跳转、终态续接及原创 C 下载。下载应包含依赖、类型与调用前提，不伪装为任意 C 编译器。自测覆盖每个结构及约定，支持错后重选与独立保存。
