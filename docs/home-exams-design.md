# 首页与历年真题练习

2026-11-11。用户已确认浅色卡片式方案，并授权后续常规设计与实现自主完成。

## 设计与实施顺序

1. 独立门户首页：米白底色、彩色数据结构矢量插画、八张章节入口，桌面四列两行，窄屏两列或一列。悬停、键盘焦点及按压反馈，遵从减少动态效果设置。
2. 原顺序表实验移至 sequence.html，原进度键保持不变。更新全站章节链接及返回首页入口。线性表卡片包含顺序表与链表入口。
3. 每章练习增加独立的历年真题入口，统一真题页按章节、年份、题型筛选。范围为考试标注年份 2017—2026，选择题与综合题分别处理；综合题通过对照解析自评，不宣称自动批改任意代码。
4. 真题数据与界面分离。每题记录年份、题号、章节标签、题源、版本与核验状态。原题、整理说明及原创练习不得混淆；配图缺失或答案有争议时明确标注。不同年份和章节不强行凑题。
5. 新练习记录采用独立键，不改写旧章 mastered/completed。浏览器禁用存储时仍能学习。筛选不丢弃已有作答。
6. 验证八个入口、九个原实验页、桌面及手机布局、键盘操作、动效偏好、题目筛选、答题保存和旧章记录。执行全量算法测试；算法和同源 C 未修改时不重复进行 C 对照。
