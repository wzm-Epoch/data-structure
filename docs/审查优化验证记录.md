- `node --test tests/*.test.cjs`：原 73 项通过；增加壳层回归后 `npm test` 为 77 项通过。
- 串实际 C 对照：7560 场景；树：155 场景；顺序表：216 场景；链表：898 场景；栈队列：466 场景；图：116 场景及 12 下载片段；查找：177 终态与 2747 逐赋值状态；算法：105 场景；排序：452 场景，全部通过。
- 浏览器使用本机 Chrome + 已存在的 Playwright Core，`file://` 打开九页；360px 宽度检查导航、清除入口、前进回退、按钮焦点方向键、页签与重复预测，未捕获页面异常。

- 算法章全排列 5 项产生 6881 个执行步骤（不含初态）；在多个位置与首尾跳转检查代码/课程 DOM 身份不变、日志数量有界、中间代码高亮可见。终态没有执行代码行，按引擎原契约不显示高亮。
