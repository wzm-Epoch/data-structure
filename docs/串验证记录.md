## 范围与限制

- 浏览器交互在本地 HTTP 实测；未通过工具实测 file 双击入口。资源全部相对路径、无 fetch、CDN、账号或 API。
- 下载按钮生成包含声明/计数函数/当前算法、不含 main 的 C 片段；代码组成已由同源编译验证，本轮未实测下载文件保存流程。
- 字符限可打印 ASCII；堆分配及链式串只提供概念，首版逐行演示使用显式 length 定长串。网页容量限制 1–32 为演示规模；可修改导出 C 的 M。
- 求子串使用临时 U 且整结构提交，时间 O(M+k)、辅助 O(M)；替换也含 O(M) 初始化/提交成本。其他输入串按指针传参，避免按值复制整个结构而隐含额外容量开销。
- 解释器只对固定语句树求值，用户文本作为数据，不作为代码；不是任意 C 编译器。快照保存、网页渲染及输出存储不计入所标算法辅助空间。
