# 树与二叉树设计

2026-11-05。用户已明确全部功能及分阶段顺序，并授权常规实现安排。

采用独立 tree.html、tree.css、js/tree-engine.js、tree-content.js、tree-app.js。复用既有样式，不合并旧章引擎，避免影响旧记录。另一方案是抽取通用播放器，但会扩大旧章改动；本次保持独立播放器。进度键 zhixu-tree-v1。

固定语句描述生成原创 C 与解释执行轨迹。递归函数独立栈帧，调用、基例、子返回、接收返回分别记录。每步复制全部节点、变量、调用栈、辅助容器、输出、表项与条件。数据不参与表达式编译。

普通二叉树用独立整数身份、int32 数据、左右孩子指针。队列解析层序 null；拒绝根空而有非空项及队列耗尽后的非空项。图布局不表示内存。编辑使用节点身份，提交编辑才生成新轨迹。根层次1、深度按边数根0、高度按节点数空0。

阶段：二叉树与递归 → 线索与孩子兄弟转换 → 哈夫曼与并查集 → 对照、练习、浏览器和旧章回归。每阶段执行独立测试。

重建用唯一 int32 标识、逐段检查，申请失败释放本次已分配节点并返回失败；原输入不归重建函数所有。线索化无头节点；孩子标志0、线索1；不得循线索递归。树森林用父身份列表表达有序结构，转换与恢复保留身份次序。

哈夫曼按(权值,创建编号)稳定排序，左0右1；限制32符号、每权1..10^9保证 uint64 和 JS 精确整数范围；单符号编码0、边路径 WPL=0。并查集 parent 根自指、size仅根有效，等大小时保留第一个代表元；按大小合并及可选压缩。

自动检查独立参考结果、快照隔离、非法输入和分配失败。页面同源 C 实际编译运行最终状态对照，不声称已逐步对照机器执行状态。浏览器实测播放、回退、编辑、预测、暂停、自测和旧章导航。原创教学，不声称教材或考纲完全覆盖。
