## 表示约定

- 数组下标从 0 开始，逻辑序位从 1 开始。元素为 32 位整数，允许重复，不按值去重。
- 顺序栈：top 指向下一次入栈位置，也等于元素个数，空栈 top == 0；物理容量 M，满栈 top == M。入栈先写 data[top] 再增加 top，出栈先保存 data[top - 1] 再减 top。逻辑范围外保留旧值并标为无效元素。
- 链栈：为遵循项目链式结构统一带头节点的约定，top 固定指向头节点 H，实际栈顶是 top->next；判空 top->next == NULL。另在概念对比中说明不带头节点的常见表示 top == NULL，但不混用到本页算法。
- 循环队列：front 指向队头元素，rear 指向下一次入队的空位；物理容量 M，预留一格，有效容量 M - 1。判空 front == rear；判满 (rear + 1) % M == front；长度 (rear - front + M) % M。出入队均按模 M 更新对应下标。支持设置初始 front，实际演示绕回。
- 链式队列：带头节点 H，front 指向 H，rear 指向最后数据节点，空队列 front == rear == H。删除最后元素时必须把 rear 恢复为 H。
- 链式结构无固定判满条件，malloc 失败返回 false，并保留原结构；演示初始最多 8 个数据节点仅是显示限制。初始头节点由调用方提供且有效，头节点初始化分配失败不在操作模拟范围内。
- 所有结构对象和输出指针均有效；空栈/空队列取值与删除返回 false，输出参数保持未写入。空/满判断的 false 本身是正常判断结果，不表示函数执行失败。

## 基本操作及课程

两类栈分别实现初始化、判空、取栈顶、入栈、出栈；顺序栈另实现判满。两类队列分别实现初始化、判空、取队头、入队、出队；循环队列另实现判满。链式初始化重设已提供的空头节点，不对已有非空结构直接覆盖，避免泄漏。

说明栈的后进先出与队列的先进先出、关键变量、存储区别、括号匹配/调用栈与任务缓冲等应用背景；应用算法只作概念介绍。双端队列、共享栈、表达式求值和递归应用标为规划，不伪装成逐行演示。

各操作提供原创 C 示例、复杂度及前提。上述操作在合法结构和通常的常数时间内存分配模型下为 O(1) 时间、O(1) 辅助空间；链式入操作增加一个节点，完整结构占 O(n) 空间，数组结构占 O(M) 存储。网页快照开销不计入算法复杂度。

设置结构对比、常见错误及带解析原创自测，重点覆盖 top 两种含义、rear 含义、预留一格、模运算、末节点删除和分配失败。

## 状态与交互

初始状态明确标注尚未执行，其后每步为对应 C 语句执行后状态。C 语句用稳定标记映射行号。每步独立复制数组、节点及存活状态、指针、标量、读取字段、改写字段、条件结果、输出、返回值与解释。说明本步读取什么、修改什么和原因。局部指针赋值不误标为节点字段读取。

支持前进、回退、播放/暂停、重置、速度、时间线跳转、执行记录、预测下一步，以及数组写入/指针改写/释放前的适用暂停点。回退直接恢复完整快照；输入更改提示待生成，生成后重建整条轨迹。提供普通、空、单元素、满、重复值、绕回、申请失败等适用预置。

顺序栈同时标注物理下标和栈底/栈顶；循环队列图显示固定物理格子、front/rear 与单独的逻辑出队次序。链式图只按快照 next 画箭头，说明节点位置不代表连续内存；释放后不再显示可读取字段。节点申请后未初始化字段显示未初始化，不当作 NULL。
