# 知序 · 数据结构学习实验室

在线使用：[打开学习实验室](https://wzm-epoch.github.io/data-structure/)。无需安装依赖，选择章节即可学习；进度保存在当前浏览器。

面向 408 学习的中文本地交互网页。现包含线性表、栈队列、串、树、图、查找、排序和算法设计，共 8 个主题、9 个实验页面（线性表分为顺序表与链表）：顺序表 3 个操作、链表 13 个算法和 1 个错序实验、栈队列 22 个基本操作、串 16 个算法入口，树章节另有26个入口与24道原创自测题，图章节12个入口及26道自测，查找章节43入口与32道自测，排序章节20入口与30道自测，算法章44个新实验与36道自测，共198道原创自测题。

## 打开与使用

直接双击本目录的 `index.html`，进入浅色八章门户首页。线性表卡片可选择顺序表或链表；顺序表实验现位于 `sequence.html`。章节演示和首页插画离线可用，无需账号或 API。保留 CSS、`assets/` 和 `js/` 与入口文件的相对位置。

`exams.html` 提供 2017—2026 年真题整理练习，支持章节、年份和题型筛选。题意整理与来源原题区分显示；依赖原图的题目需联网查看题源，答案有争议的题目不自动判分。新真题记录与原有章节进度分别保存。

通过页面右上角进入“链表实验室”，也可直接打开 `linked.html`。链表页面还需要保留 `linked.css`。两章的学习记录独立保存。

1. 在“逐行演示”中选择插入、删除或按位查找。
2. 填写初始整数列表、容量、位置，插入操作还需填写插入值。留空列表表示空表。
3. 点击“生成演示”，再点击“下一步”或“播放”。输入更改后要重新生成，旧演示不会被静默改动。
4. “上一步”、进度条和重置可以检查任意步骤；所有高亮显示刚执行完的代码行。
5. 勾选“预测下一步”后，点击“下一步”先作答，再揭示状态。预测模式暂停自动播放；拖动进度条仍可自由查看。
6. 浏览器将成功完成的操作和答对的练习保存在本机。可从侧边栏或移动端页脚清除，或在练习页重新练习。不同浏览器的记录不共享，禁用本地存储时仍可学习。

演示页中，焦点在普通页面或播放器按钮上时，左右方向键可前进/回退；输入、链接、页签和可编辑区域保持各自的键盘行为。焦点在普通页面时空格可播放/暂停，在按钮上时空格触发该按钮。学习页签支持左右方向键及 Home/End 切换。

## 链表实验室

- 单链表：按位插入、按位删除、按位查找、按值查找、遍历、原地逆置、头插建表、尾插建表。
- 非循环双链表：按位插入、按位删除，同步观察 next 与 prior。
- 循环单链表：插入、删除、遍历，尾节点指回头节点 H。
- 插入错序实验：故意先写 p->next，再写 s->next，观察自环和原后继链失去入口。实验在异常处停止。
- 10 张概念卡、6 类结构对比、6 个易错点和 13 道原创自测。

每种算法支持单步、回退、播放、预测和执行记录跳转。可设置在改写链接前、释放前或链接/内存操作前自动暂停；再次播放会执行此前暂停的那一步，再继续到下一个暂停点。

点击图中的节点或使用节点观察器，查看 data、next、prior、持有该节点的指针。释放后的节点只显示观察墓碑，不再显示可读取的字段。节点排列是展示布局，不表示相邻内存。

“快速试试”提供空表、单节点、首位、尾部、越界、重复值和申请失败等适用示例。输入规模最多 8 个初始数据节点，插入可得到第 9 个节点；这是可视化规模限制，不是链表的固定容量。

建表算法从已创建的空头节点开始，输入是待建表数据流。可指定第 k 次 malloc 失败：普通插入失败不改动原表；建表中途失败保留已接入的部分，调用方负责后续管理。

“用结果继续操作”会把当前有效结果作为下一次输入；建表完成后会切回普通插入示例。节点身份会重新编号。若结果有 9 个元素，需先调整为最多 8 个再生成。下载按钮导出当前 C 算法片段，包含结构体但不包含 main；错序实验不导出为可用算法。

## 内容边界与约定

- 本工具不是 C 编译器。JavaScript 引擎按预置 C 算法的语义生成状态快照，不支持任意代码编辑执行。
- 原创代码不声称复刻王道 2027，当前也没有完整核对当年考试大纲。
- 逻辑位置从 1 开始，数组下标从 0 开始；容量可选 6、8、12。
- C 示例假定 L 是有效顺序表，length 满足范围条件；查找与删除的输出指针 e 有效。数组初始未用格子显示“·”，不代表真实 C 内存一定为 0 或空值。
- 页面显示的 `*e` 是通过输出指针写回的值，不是指针地址。
- 删除后逻辑表外的旧值会继续显示，防止将逻辑删除误解为清空内存。
- 页面统计的移动次数只计复制原有元素，不计写入新元素和保存输出值。
- 不带头节点链表、循环双链表和静态链表目前只有概念对比；树、图、查找、排序与算法设计章节已开放。

## 栈与队列实验室

直接打开 `stack-queue.html`，或使用旧章节顶部导航。需要保留 `stack-queue.css`、共用样式及 `js/stack-queue-*.js`。无需联网或安装依赖。

四类结构共 22 项操作：顺序栈和循环队列分别提供初始化、判空、判满、读取、添加、移除；链栈和链式队列分别提供除判满外的五项。链式结构没有固定容量判满，入操作可模拟 malloc 失败。链式初始化要求调用方已提供空头节点，不覆盖非空链。

顺序栈 top=0 为空，top 是下次入栈下标，栈顶为 data[top−1]，满栈 top==M。循环队列 front 指向队头，rear 指向下次入队位置，预留一格，可容纳 M−1 个元素。链栈和链式队列统一带头节点 H。顺序栈输入顺序为栈底到栈顶；链栈输入为栈顶到栈底；队列为队头到队尾，输入框和图中均有标注。

支持逐句前进、完整回退、播放暂停、重置、速度、时间线和执行记录跳转、预测下一步以及关键步骤前暂停。数组格子保留逻辑删除后的旧值；释放节点隐藏字段。循环队列可填写初始 front，使用“下标绕回”或连续复用结果观察绕回。输入修改后需重新生成；非法格式保留原轨迹并显示错误。

本章包含 8 张概念卡、4 类对比、6 个常见错误和 12 道带解析自测；独立保存进度，清除本章记录不会清除旧章。链式初始最多 8 个数据节点，新增可到 9 个，仅为展示限制；超过 8 个的结果不能直接复用。

代码分为 `js/stack-queue-engine.js`（纯轨迹与同源 C）、`js/stack-queue-content.js`（课程）、`js/stack-queue-app.js`（图示与交互）。使用 `node --test tests/*.test.cjs` 验证；实际 C 对照执行 `node tests/stack-queue-c-parity.cjs "D:\Dev-Cpp\MinGW64\bin\gcc.exe"`。设计与实测范围见 `docs/栈与队列设计.md` 和 `docs/栈与队列验证记录.md`。


## 串与模式匹配实验室

入口 `string.html`，也可从旧三章顶部导航进入。沿用已有风格，可离线运行；引擎、课程、界面分别为 `js/string-engine.js`、`js/string-content.js`、`js/string-app.js`，专属样式 `string.css`。本章记录使用 `zhixu-string-v1`，清除不影响其他章节。

- 11 个基本操作：赋值、复制、判空、取长度、清空、字典序比较、连接、子串、插入、删除、替换。
- BF、next 构建及 KMP、nextval 构建及 KMP；匹配可选首个/全部、重叠/非重叠。
- 显式 length 的定长顺序串，M 为 1–32（网页演示规模），有效范围 data[0..length-1]。支持可打印 ASCII 32–126，空格保留并显示为 ␠；超容量及不支持字符明确报错。算法容量不足返回 0，保持原串，不截断。C 片段可修改 M 后独立编译，网页不是任意 C 编译器。
- 下标从 0、逻辑位置从 1、匹配失败 0；空模式首个位置为 1，全部位置为 1..n+1。next[0]=nextval[0]=-1；额外 m 项保存完整匹配的终端边界，绝不读取 P[m] 或 P[-1]。
- 替换左到右扫描原串中的非重叠匹配，新内容不再参与；空模式替换拒绝。子串结果写回 S。子串/删除允许 p=n+1,k=0。输入串对象不别名。
- 单步、回退、播放暂停、重置、调速、时间线、执行记录跳转、预测错后重选；失配、回退、填表、找到匹配前可自动暂停，再次播放越过当前暂停点。输入改变会暂停，点击生成重建完整轨迹。初始未执行，其后均为执行后状态；分别赋值的中间状态可能暂不满足稳定的 i/j 对齐关系。
- 对比实验使用同一表单的 S/P 与策略，分别统计预处理和匹配字符比较；点击按钮切换完整轨迹，保留各自游标。只计 Eq/Cmp 比较字符对，不计条件中的整数比较或赋值。nextval 构表的额外比较计入预处理。
- 14 张概念卡、8 个易错点、15 个预置示例、20 道带解析自测（错后重选，独立保存）。左右方向键步进，空格播放，输入控件聚焦时不拦截；页签支持方向键切换。

实际 C 对照：`node tests/string-c-parity.cjs "D:\Dev-Cpp\MinGW64\bin\gcc.exe"`。可传自己的 GCC 路径。自动回归：`node --test tests/*.test.cjs`。详细设计与验证范围见 `docs/串设计.md`、`docs/串验证记录.md`。下载按钮输出当前算法及声明、计数辅助函数的 C 片段，不含 main。


## 树与二叉树实验室

入口 `tree.html`，旧四章顶部导航也可进入。无联网依赖，原创讲解与 C，不声称复刻教材。`js/tree-engine.js`、`tree-content.js`、`tree-app.js` 分离算法、课程、界面；`tree.css` 为专属样式。独立记录键 `zhixu-tree-v1`，旧章记录不变。

26个入口：递归/非递归三种遍历、层序、树高/节点/叶统计、镜像、按身份查找与路径、LCA、两种重建、中序线索化及遍历、树森林转换及恢复、哈夫曼构造与码表、逐行编码/解码、并查集初始化/查找/按大小合并/压缩。

- 层序输入 JSON，例如 `[1,null,2,3]` 按队列解析；3是2的左孩子。null表示空，数据是int32，允许重复。节点身份N1起，独立于数据。根层次1、深度按边数根0、树高按节点数空0。
- 普通二叉树最多64节点；哈夫曼最多32符号，每权1..10^9（uint64_t累加/WPL），消息最多64符号、解码最多2048位；并查集1..32元素、最多64前置操作。这些是展示上限，不是数学定义。
- 可视化编辑先修改草稿；提交后生成全新轨迹，存活节点身份保留。文本层序重新解析则重编号。镜像、重建、去除线索后的树及哈夫曼结果可继续作为普通树输入；森林结果可继续恢复；并查集续接保存parent/size，修改大小或前置序列会放弃续接初态。
- 递归调用栈显示独立参数、局部变量、暂停的调用、返回位置与返回值。指针以身份编号展示，0为NULL。空调用同样可观察。高度返回展示max(l,r)+1。栈/队列独立展示。访问序列只在访问语句追加。
- 线索无头节点，标签0孩子/1线索；虚线橙为线索，首前驱与末后继NULL。终态节点观察器可查看指定身份的中序前驱、后继。
- 森林输入为父身份数组，节点按1起编号，0表示无父；如 `[0,1,1,2,0,5]`。同一父的孩子顺序按输入身份顺序。左首孩子/右下一兄弟；恢复保留身份与顺序，同时对照先根/二叉先序、后根/二叉中序。
- 重建输入是唯一int32标识；长度、集合、递归划分不一致直接拒绝。可指定第k次申请失败，释放本次部分构建。哈夫曼失败由包装层逐句释放申请池；不释放调用方原树。普通遍历不申请节点。
- 哈夫曼按(权值,创建编号)选择，左0右1。单符号码0、树WPL0，明确区分工程码长和树边路径。编码面板支持快捷往返，也可生成完整编解码轨迹；解码返回0时，部分输出不能当作完整结果。
- 并查集下标0起，parent根自指，size仅根有效；图节点编号=下标+1。等大小保留Union第一个代表元。按大小合并与压缩的序列均摊O(α(n))，不是严格O(1)。
- 支持前进、完整回退、播放暂停、速度、时间线、日志跳转、关键步骤前暂停、预测错后重选、当前C与依赖下载（不含main）。左右键步进、空格播放；聚焦输入控件时不拦截。14张概念卡、8个错误专题、24道带解析自测独立保存。

验证命令：`node --test tests/*.test.cjs`；`node tests/tree-c-parity.cjs "D:\Dev-Cpp\MinGW64\bin\gcc.exe"`。实际范围见 `docs/树验证记录.md`，设计见 `docs/树设计.md`。二叉排序树、AVL、红黑树、B树、B+树是后续查找章节衔接，本章没有实现。


## 图实验室

直接打开 `graph.html`，或从任一旧章顶部导航进入。独立记录键 `zhixu-graph-v1`，原学习记录保留。资源为本地相对路径，无账号、联网或API。

图模型最多8顶点，支持有向/无向、带权/无权、孤立点和非连通。自定义JSON、顶点/边增删和权值编辑，拒绝自环、重边、缺失端点及非法权值；权为整数且绝对值≤10^6。无权边w=1。id稳定，C下标按vertices顺序0起；文本输入自己提供id，删除后保留其他身份。图形可拖动布局，不改变语义；逻辑提交后重新生成。非法提交保留原轨迹并显示错误。

12入口：递归DFS、帧式非递归DFS、BFS、无向连通分量、BFS最少边数路径、有向可达、Prim/Kruskal最小生成森林、Dijkstra、Floyd、Kahn拓扑排序、AOE关键路径。邻接编号递增；整图遍历从起点循环编号启动未访根；可达与BFS路径强制仅指定源，分量强制整图。Prim/Kruskal只接受无向带权，Dijkstra拒绝任何负权。Floyd显示负环影响点对，禁止恢复其普通路径。

矩阵和邻接表同时显示并可与图形互选，编辑区支持逻辑边、矩阵、邻接表三种JSON导入导出及转换；“·”无边、0零权，对角空路径距离0另算。原创C使用矩阵扫描，邻接表是同步存储对照。十字链表、邻接多重表仅概念示意，没有逐行维护算法。下载为同源函数及全局声明/初始化约定，不含main和输入解析器。

单步、完整回退、播放、暂停、调速、时间线、记录跳转、预测错后重选、关键步骤前暂停和观察器。所有步骤为独立执行后快照，初态尚未执行。统计矩阵候选位置/逻辑边/三元组检查、松弛尝试、距离改写和入队，不使用动画时间衡量性能。

## 排序实验室

入口 `sort.html`，旧七章顶部导航均可进入，可离线使用。20个入口覆盖直接/折半插入、希尔、普通/提前结束冒泡、末元Lomuto快速、三路快速、选择、堆、递归/迭代归并、双段归并、计数、LSD基数、桶、初始归并段、外部二路/多路/败者树归并、置换—选择。

输入整数或 `3A,1B,3C`，身份标签不参与内部比较。支持int32全范围、空输入、升降序；数组下标0起，逻辑位置1起。展示最多32条记录。计数排序值域最多256，超限明确拒绝。希尔默认逐次减半，自定义正整数增量严格递减且末项1。双段归并的split为右段起始下标。

支持完整快照前进/回退、播放暂停、调速、时间线、执行记录跳转、预测错后重选、关键事件前暂停、结果保留身份续接及当前原创C下载。记录卡、带零轴的正负柱状图、堆数组/树对应、败者树比赛路径、辅助区与完整快照观察器可配合阅读。柱高采用带最小可见高度的对数压缩，标签仍显示真实关键字；缩放不参与计算。

## 算法设计与应用

入口 `algorithm.html`，九章顶部导航相通；独立进度键 `zhixu-algorithm-v1`。44个新实验、7组同输入对比、10个易错实验、36道带解析原创自测。折半、归并、MST、哈夫曼通过思想页复用旧章入口，不另造不一致实现。

- 贪心与DP：活动选择、分数背包、短任务优先、找零对照、硬币组合、二维/一维0/1背包、完全背包、LCS、严格LIS、编辑距离、网格计数/最小和、矩阵链乘。

- 技巧：有序两数之和、有序合并、固定窗口、无重复字符子串、前缀与差分、扫描/单调栈下一个更大、单调队列窗口最大、非负有序分段容量二分答案。

先选算法，再修改带默认示例的 JSON，点击生成。字符串内空格保留，ASCII 32–126；每个输入框上方声明适用域。单步/完整回退、播放调速、事件前暂停、时间线/日志、错后重选预测、完整观察器和固定种子例子可用。修改输入后需重新生成，非法输入保留旧轨迹。C下载包含本次输入、main、固定函数库与计数辅助操作，C11可直接编译运行。

DP用K/R区分未计算、不可达及合法0。恢复LCS、LIS和网格的原始P顺序为逆序，页面另给正序路径；背包输出原输入身份。分数背包显示精确分数而非整数商。分治最大子数组本体O(n log n)，当前教学恢复额外枚举O(n²)，复杂度说明明确区分。完全背包为保证一维状态的解恢复可靠，每次同步复制组成向量，其教学开销另列。
